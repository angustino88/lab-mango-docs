# Developer handbook

One place for Lab Mango's engineering documentation: architecture, design specs, conventions, API standards,
feature specifications, decisions and internal rules, for both the frontend and the backend.

Engineering docs **live next to the code** in their own repository and are reviewed with the code. This site copies
them on every build, so it always shows what is on `main`. See [How docs are synced](./docs-workflow.md).
