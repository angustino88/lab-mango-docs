# Lab coordinator guide

A lab coordinator keeps the lab running. You can do everything in the [lab user guide](../lab-user/index.md), plus:

| Area | Menu | Guide |
|---|---|---|
| Decide long bookings, manage anyone's booking | Booking Calendar, My Bookings | [Approving bookings](./approving-bookings.md) |
| Rooms, stations, benches and how they connect | Spaces | [Spaces](./spaces.md) |
| Equipment in 12 categories, and software licenses | Equipment | [Equipment and licenses](./equipment.md) |
| Purchases, expenses and the finance report | Finance | [Finance](./finance.md) |
| Usage analytics and live device monitoring | Insights | [Insights](./insights.md) |
| Answer and route support tickets | Support tickets | [Support desk](./support-desk.md) |

Your rights are checked by the server on every request, not only hidden in the menu. Admins have all coordinator
rights too.
