# Finance

| Page | Use it to |
|---|---|
| **Purchases** | Create purchase orders, add line items (from the catalog or as a custom item), and track orders from **Draft** to **Ordered** to **Received** (or **Cancelled**) |
| **Expenses** | Record facility expenses (for example room expenses and recurring agreements) in the expense ledger |
| **Finance Report** | See the financial overview: monthly cash flow, monthly commitments, budgeted obligations, by period |

Purchase costs can be allocated to a bench, station, equipment unit or license, so you can see what each resource cost.

:::tip
Use the period filters (last week, month, quarter, year) on the Finance Report to compare spending over time.
:::
