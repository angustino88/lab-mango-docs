# Lab Mango user guides

Lab Mango manages the lab: rooms, stations, benches, equipment, bookings, licenses, purchases, expenses and
monitoring. These guides explain how to use it. Pick the guide for your role.

| Your role | You use Lab Mango to… | Guide |
|---|---|---|
| **Lab user** | book benches, follow your bookings, check the dashboards, ask the lab team for help | [Lab user guide](./lab-user/index.md) |
| **Lab coordinator** | everything a lab user does, plus approve bookings, keep spaces and equipment up to date, track purchases and expenses, handle support tickets | [Lab coordinator guide](./lab-coordinator/index.md) |
| **Lab admin** | everything a coordinator does, plus decide who holds which role and configure the support desk | [Lab admin guide](./lab-admin/index.md) |

Roles build on each other: **admin > coordinator > user**. An admin can do everything a coordinator can,
and a coordinator everything a user can.

New to Lab Mango? Start with [Getting started](./getting-started.md).

:::tip Not sure which role you have?
Open Lab Mango and look at the left menu. If you see **Spaces**, **Equipment**, **Finance** and **Insights**, you are a
coordinator or an admin. If you only see the dashboards, bookings and support tickets, you are a lab user.
:::
