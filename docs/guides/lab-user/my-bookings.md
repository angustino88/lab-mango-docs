# Managing your bookings

**My Bookings** lists every booking you created.

- Search by status, bench name, booking code and more.
- Filter columns such as **Status** and **Approval**.
- **Reset** clears filters and sorting; **Refresh** reloads the list.
- **New Booking** creates a booking without going through the calendar.

## Change a booking

1. Select the **Edit** (pencil) icon on the row, or open the booking in the calendar and select the pencil.
2. Change the times, bench, project or reason in **Update Booking**.
3. Select **Save**.

Completed, expired and cancelled bookings cannot be changed.

:::caution Extending past 4 hours
If the new duration is longer than 4 hours, the booking needs approval again and returns to **Pending**.
:::

## Cancel a booking

Open **Update Booking**, set **Status** to **Cancelled**, add a reason, and save. Cancel as early as you can so the
bench is free for someone else.

## Rejected bookings

If a coordinator rejects your booking, the **Approval** column shows **Rejected**. Hover over it to see who decided. Create a new booking with a shorter time, or talk to your coordinator.
