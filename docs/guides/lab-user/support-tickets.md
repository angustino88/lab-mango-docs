# Support tickets

Use **Support tickets** to ask the lab team for help: a broken bench, missing equipment, an access problem, or any
other request.

## Create a ticket

1. Open **Support tickets** and create a new ticket.
2. Enter a **Subject** and a **Description**, and choose the **Request type** and **Category**. Set a **Priority**
   if your lab allows requesters to choose it.
3. Attach screenshots or files if they help. Some lab setups scan attachments first; a file can be downloaded only
   after it is marked clean.
4. Where you can, link the affected bench or equipment. The resource's history then shows the incident.

## Follow a ticket

You see the tickets you requested, created or watch. Filter by **Open**, **In progress**, **Resolved** or
**All tickets**. On a ticket you can:

- add a **Public reply**; a reply while the ticket waits for you resumes it;
- watch or unwatch it to get, or stop getting, updates;
- edit it while it is still open;
- rate the support (1–5) after it is resolved.

The lab team works to response and resolution targets set by priority, and you are notified when the ticket changes.
